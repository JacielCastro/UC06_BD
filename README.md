# 🗄️ Estudos de Banco de Dados MySQL

Este repositório foi criado para documentar minha evolução e aprendizado em Banco de Dados Relacionais. Aqui armazeno scripts de criação, consultas e modelagens desenvolvidas durante o curso.

## 🚀 Objetivo
O foco principal é praticar os fundamentos de SQL, desde a modelagem conceitual até a implementação de consultas complexas, utilizando o **MySQL Workbench** como ferramenta principal.

## 🛠️ Tecnologias e Ferramentas
* **MySQL Server**: Banco de dados relacional.
* **MySQL Workbench**: Utilizado para administração e modelagem visual (DER).
* **Git/GitHub**: Controle de versão dos scripts.

## 📁 Estrutura do Repositório
* `/Arquivo`: Contém arquivos `.mwb` para manipulação em MySQL Workbench.
* `/Diagramas`: Armazena os modelos visuais e diagramas de entidade-relacionamento (DER).

## 📊 Modelagem Visual
O projeto conta com um diagrama visual para facilitar a compreensão da estrutura das tabelas e seus relacionamentos (Chaves Primárias e Estrangeiras).

> **Dica:** Para visualizar o diagrama, acesse a pasta `/imagem` deste repositório.

## 🧠 Conceitos em Estudo
- [x] Criação de Databases e Tabelas.
- [x] Definição de Tipos de Dados (INT, VARCHAR, DATE, etc).
- [x] Relacionamentos entre tabelas (1:1, 1:N, N:N).
- [ ] Consultas com filtros e ordenação (WHERE, ORDER BY).
- [ ] Junções de tabelas (JOINs).
